# Basename Checker

Simple Basename availability checker for Base.

## Features

- Check if a Basename is available
- ENS namehash support
- Base Mainnet RPC integration
- Fast and lightweight

## Tech Stack

- HTML
- JavaScript
- ethers.js
- Base RPC

## How It Works

This tool checks Basename ownership using the ENS Registry contract on Base.

If the owner address is:

- Zero address → Available
- Non-zero address → Registered
